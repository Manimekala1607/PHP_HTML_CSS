# WEB DESIGNING & DEVELOPMENT

## Overview

This repository contains 28 Web Designing and Development (WDD) laboratory programs developed using HTML5, CSS3, and PHP.

The programs are designed based on the WDD laboratory syllabus and cover various real-world web application concepts such as registration systems, billing systems, calculators, validation systems, login modules, booking systems, and result processing applications.

Each program demonstrates the implementation of frontend and backend web development concepts with a simple, user-friendly interface.

## Features

- 28 WDD practical programs
- HTML5 for webpage structure
- External CSS for styling
- PHP for server-side processing
- Form validation
- User-friendly interfaces
- Responsive layouts
- POST method implementation
- Different color themes for each program
